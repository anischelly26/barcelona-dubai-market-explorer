# Two-minute demo script

1. Open the dashboard and point out the data-mode badge. Explain that the UI consumes FastAPI and falls back to labelled demo data when the API is offline.
2. Filter by property type and budget. Show that all metrics, markers and selected-property details update together.
3. Click markers on both OpenStreetMap views. Highlight that database mode uses PostGIS geography and radius queries.
4. Switch between the 3, 6 and 12 month trend windows. Explain the EUR/m² normalization across EUR/AED and sqm/sqft.
5. Change the ROI assumptions. Contrast gross yield with net yield after vacancy, costs and acquisition fees.
6. Open `/docs` on the API and demonstrate the property, trend, nearby and ROI endpoints.
7. Close with the ingestion architecture, automated tests, Docker Compose and responsible-source policy.

Recording guidance: use 1080p, browser zoom at 90%, no personal tabs visible, and keep the final video between 90 and 120 seconds.
